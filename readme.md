\# AMD HD Hex Modifier



Script desenvolvido para automatizar a leitura e modificação de endereços hexadecimais em arquivos binários/ROMs.



\## Funcionalidades

\- Leitura direta de bytes e offsets específicos.

\- Substituição segura de valores hexadecimais.

&#x20;para transformação lógica da HD6700 de 1GB GDDR5 VRAM para 2GB GDDR5 VRAM.

\- Geração de backup/arquivo modificado.



\## Como usar

1\. Certifique-se de ter o Python instalado.

2\. Execute o script no terminal:

&#x20;  ```bash

&#x20;  python hd6700\_hex\_modifier.py
